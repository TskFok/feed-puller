# 订阅新增按钮移至右上角设计

## 目标

将订阅页面的“新增订阅”操作从订阅列表上方的独立工具栏移至页面标题栏右上角，使其与 Prowlarr 搜索页的右上角操作入口保持一致。

## 布局与交互

- 在订阅页标题栏中保留标题“订阅”和现有说明文案。
- 将“新增订阅”主按钮置于标题栏右侧；继续使用加号图标、主按钮样式和现有点击处理。
- 移除原有仅包含该按钮的订阅工具栏，避免标题与列表之间留下额外空白。
- 窄屏下沿用标题栏的单列换行规则，按钮在新行中右对齐。

## 实现边界

- 仅调整 `web/src/App.tsx` 的订阅页面结构和 `web/src/styles.css` 的布局选择器。
- 不改变新增订阅弹窗、表单字段、接口调用、权限、列表、分页或其他页面。
- 不为通用 `Header` 组件增加操作区 API；该能力当前只有订阅页需要，保持变更局部化。

## 可访问性

- 保持按钮的可见名称“新增订阅”、图标的 `aria-hidden` 与原有按钮语义不变。
- DOM 顺序保持标题/说明在前、操作按钮在后，键盘操作和焦点行为不变。

## 验收与测试

- 宽屏时，“新增订阅”显示在订阅标题栏右上方。
- 窄屏标题栏换行后，按钮仍右对齐。
- 列表上方不再渲染独立的订阅工具栏空白。
- 点击按钮仍可打开既有“新增订阅”弹窗。
- 运行前端测试与生产构建，确保结构和样式改动未引入回归。
