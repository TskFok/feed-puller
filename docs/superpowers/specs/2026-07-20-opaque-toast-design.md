# 不透明操作提示设计

## 目标

将成功和失败操作提示（Toast）改为不透明，避免页面内容透过提示卡片影响文字可读性。

## 范围

- 仅调整 `.toast` 的背景样式。
- 成功与失败提示均使用当前主题下的实色面板背景。
- 保留既有边框、状态色、阴影、入场动画、自动关闭和可访问性行为。
- 不修改弹窗、侧栏或其他玻璃拟态组件。

## 实现

在 Toast 的专用样式中覆盖共享玻璃面板规则，使用 `var(--glass-panel-solid)` 作为背景色。该变量在深色主题为深蓝实色，在浅色主题为白色，因此可同时满足双主题下的完全不透明要求。

## 验证

为 Toast 测试添加断言：成功和失败提示渲染后都使用不透明背景变量对应的样式；再运行 Toast 测试与前端构建，确认类型检查、测试和生产构建均通过。
