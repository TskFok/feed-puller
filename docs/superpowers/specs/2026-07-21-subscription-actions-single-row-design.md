# 订阅列表操作按钮单行设计

## 目标

订阅列表每行的“拉取、编辑、复制、删除”四个操作按钮在所有视口宽度下均保持单行展示，不再因可用空间不足而折为两行。

## 方案

- 仅调整订阅列表操作区 `.subscription-actions` 的样式。
- 覆盖通用 `.actions` 的换行规则，使用 `flex-wrap: nowrap`。
- 将订阅表的操作列表头和单元格设为按内容宽度布局并禁止文本换行。
- 当屏幕宽度不足时，继续由既有 `.table-wrap` 的横向滚动承接溢出；不缩小按钮、不隐藏文字、不改变其他列的内容规则。

## 范围与兼容性

- 不改动按钮文案、图标、可访问名称、禁用状态或点击行为。
- 不影响其他列表使用的通用 `.actions` 样式。
- 保持已有表格最小宽度和横向滚动机制。

## 验收与测试

- 宽屏与窄屏下，每行四个操作按钮均在同一行。
- 窄屏出现横向溢出时，订阅表容器可以横向滚动查看完整操作区。
- 操作按钮现有的视觉样式和交互测试仍然通过。
- 增加前端测试，验证订阅操作单元格使用专属单行布局类；运行前端测试和生产构建。
