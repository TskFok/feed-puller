# 列表长文本截断与悬停查看设计

## 目标

防止当前应用所有数据列表中的超长文本换行、撑高行高或挤压列布局。长文本在列表中保持单行省略，并在鼠标悬停时通过原生提示显示完整内容。

## 范围

覆盖以下视图及其列表文本字段：

- 订阅列表及拉取预览弹窗。
- 下载中与下载完成列表。
- 通知历史与重命名记录。
- AI 配置列表。
- Prowlarr 搜索结果卡片标题。

状态、时间、数值、进度、操作按钮与设计上需要分行展示的订阅调度摘要不在截断范围内。

## 方案

新增前端复用组件 `TruncatedText`，接收文本和值的可选样式类：

- 输出承载文本的内联元素，保留完整文本作为原生 `title` 属性。
- 使用统一 CSS 类实现 `overflow: hidden`、`text-overflow: ellipsis` 和 `white-space: nowrap`。
- 由组件承担 `min-width: 0` 与块级宽度约束，使它可在表格单元格和卡片标题的弹性布局中正确收缩。

表格维持当前横向滚动兜底；为避免超长内容参与自动列宽计算而拉伸表格，列表表格使用固定列布局。各表仍以现有最小宽度作为窄屏横向滚动阈值。

## 使用规则

- 所有可能很长的业务文本（名称、标题、路径、通知正文、错误内容、AI 提示词与返回内容）均改用 `TruncatedText`。
- 空值回退文案保持当前行为，回退后得到的最终显示文本同时作为 `title` 值。
- 原生 `title` 由浏览器在鼠标悬停时展示完整文本；不引入自定义浮层、Portal 或额外键盘交互。
- Prowlarr 卡片标题保留既有字号、状态徽标与选择框布局，只将可伸缩的标题文本改为单行省略。

## 验收与测试

- 为 `TruncatedText` 添加组件测试：渲染完整文本、包含完整 `title` 属性，并带有统一截断类。
- 为 Prowlarr 卡片补充标题使用该组件的测试或扩展既有卡片测试。
- 运行前端单元测试和生产构建，确认类型检查、测试与打包均通过。
