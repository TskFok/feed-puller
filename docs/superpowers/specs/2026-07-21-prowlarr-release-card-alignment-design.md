# Prowlarr 结果卡片标题与操作栏对齐设计

## 目标

修复 Prowlarr 搜索结果卡片在标题过长时的布局问题：标题文本与复选框顶部对齐，超长标题在卡片可用宽度内省略，下载操作始终完整地保留在卡片底部可视区域。

## 布局

- `.prowlarr-release-card-head` 改为三列网格：固定宽度的复选框列、可收缩的标题列、按内容宽度显示的状态列。
- 复选框不再以额外的顶部外边距下移；它和标题网格行从同一顶部开始。
- 标题列使用 `minmax(0, 1fr)`；标题自身和截断文本保留 `min-width: 0` 与单行省略，长标题不得扩大卡片或挤出状态标签。
- `.prowlarr-release-actions` 明确允许在卡片宽度内收缩，下载按钮保持在右侧操作栏中；卡片的内容不因标题长度越出边界。

## 影响范围

- 仅调整 `ProwlarrReleaseCard` 的局部类名（如测试需要）和 `styles.css` 中 Prowlarr 结果卡片相关规则。
- 不修改搜索历史弹窗、搜索接口、虚拟列表数据流或卡片展示的业务内容。

## 测试与验收

- 组件测试覆盖标题行的三列布局钩子、标题截断节点和下载操作栏钩子。
- 通过样式规则测试确认：标题列可收缩、复选框无顶部偏移、操作栏受卡片宽度约束。
- 运行相关 Vitest 测试及完整前端测试；在桌面与窄宽度视口检查长标题卡片，下载按钮均可见且可点击。

## 非目标

- 不将标题改为多行或改变当前的悬停全文提示。
- 不调整卡片的视觉主题、元数据布局或虚拟列表行高策略。
