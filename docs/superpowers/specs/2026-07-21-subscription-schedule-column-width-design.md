# 订阅调度列宽收紧设计

## 目标

缩小订阅列表“拉取调度”列的最小宽度，为订阅名称与操作区释放更多横向空间。

## 方案

- 将 `.sub-schedule-cell` 的 `min-width` 从 `12rem` 调整为 `9rem`。
- 保持“上次 / 下次”两行调度摘要、标签样式、表格固定布局与窄屏横向滚动不变。
- 不调整订阅名称列、拖拽列、操作列或其他页面的表格样式。

## 验收与测试

- 调度列最小宽度为 `9rem`，相较原配置缩小 25%。
- 调度摘要继续按既有两行结构展示。
- 在窄屏可用空间不足时，继续由 `.table-wrap` 横向滚动展示完整表格。
- 运行前端测试与生产构建，确认样式调整没有回归。
