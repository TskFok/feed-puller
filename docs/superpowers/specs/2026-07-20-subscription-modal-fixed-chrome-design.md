# 订阅弹窗固定头尾设计

## 目标

将“新增订阅”和“编辑订阅”共用的订阅表单弹窗调整为固定头部、可滚动内容区和固定底部操作区。长表单滚动时，标题、说明、关闭按钮，以及取消与创建/保存按钮始终可见。

## 范围

- 只影响订阅创建与编辑使用的表单弹窗。
- 头部包含标题、说明和关闭按钮，固定在弹窗顶部。
- 底部包含取消及创建/保存按钮，固定在弹窗底部。
- 中间表单字段区独立滚动；表单提交、关闭、焦点管理和字段值不变。
- 不改变删除确认、拉取预览或其他通用弹窗。

## 实现设计

订阅表单弹窗使用纵向 flex 布局，并受原有最大弹窗高度约束。头部与底部不参与滚动；表单的字段容器作为弹性中间区域，设置 `min-height: 0` 和纵向滚动。底部操作区移出可滚动字段区，以免随表单内容滚动离开视野。

为该弹窗增加局部类名，避免改变 `.modal-panel` 的通用滚动行为。保留原有间距、分隔线、按钮状态、可访问名称及移动端宽度约束。

## 测试

- 为新增订阅弹窗添加结构性回归测试，断言固定头部、可滚动内容区和固定底部操作区存在。
- 为编辑订阅弹窗添加同样的结构性回归断言。
- 执行前端单元测试与生产构建，确保 TypeScript、表单交互和样式引用均正常。

## 自检

- 未包含未决项或占位符。
- 固定区和滚动区职责清晰，且只覆盖同一订阅表单组件。
- 不会扩展至其他弹窗，也不会修改接口或数据流。
