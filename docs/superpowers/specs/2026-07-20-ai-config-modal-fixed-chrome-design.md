# AI 配置弹窗固定头尾设计

## 目标

将“新增 AI 配置”和“编辑 AI 配置”共用的表单弹窗调整为固定头部、可滚动内容区和固定底部操作区。表单内容较长时，标题、说明、关闭按钮，以及取消与保存按钮始终可见。

## 范围

- 只影响 AI 配置创建与编辑使用的表单弹窗。
- 头部包含标题、说明和关闭按钮，固定在弹窗顶部。
- 底部包含取消及保存按钮，固定在弹窗底部。
- Provider 预设、模型、地址、高级请求参数和 API Key 等字段置于独立的中间滚动区域。
- 不改变表单提交、模型拉取、关闭、焦点管理、字段值、其他弹窗或接口行为。

## 实现设计

为 AI 配置弹窗增加局部类名，沿用订阅表单弹窗已验证的纵向 flex 布局：弹窗面板隐藏自身溢出，头部与底部设置为不收缩区；表单作为剩余高度容器，中间字段容器使用 `min-height: 0` 和纵向滚动。操作区从字段容器中移出，因此不会跟随字段离开视野。

保留现有最大弹窗高度、间距、分隔线、按钮状态、可访问名称及移动端宽度约束；不修改通用 `.modal-panel` 的滚动规则，避免影响其他弹窗。

## 测试

- 为新增 AI 配置弹窗添加结构性回归测试：固定头部、滚动字段区和固定操作区分别存在，且操作区不在滚动区内。
- 为编辑 AI 配置弹窗添加同样的结构性回归测试。
- 执行前端单元测试与生产构建，验证 TypeScript、表单交互和样式引用。

## 自检

- 没有未决项、占位符或歧义要求。
- 固定区与滚动区职责明确，只覆盖同一 AI 配置表单组件。
- 不扩展到其他弹窗，不改变 API 与数据流。
