# 列表文字垂直居中设计

## 目标

让应用中所有表格型数据列表的表头与单元格文字在行内垂直居中显示，避免多行内容或操作按钮使同一行的短文本贴近顶部。

## 范围

覆盖共享 `table` 样式所服务的订阅、拉取预览、下载中、下载完成、通知历史、重命名记录和 AI 配置列表。

Prowlarr 搜索结果为卡片网格，不在本次调整范围内。

## 方案

将共享 `th, td` 规则中的 `vertical-align` 从 `top` 改为 `middle`。所有现有表格自动继承该行为，不为单个列表增加重复覆盖规则。

文本省略、列宽、行高、操作按钮布局以及 Prowlarr 卡片布局均保持不变。

## 验收

- 表格表头与单元格内容均垂直居中。
- Prowlarr 搜索结果卡片不受影响。
- 前端单元测试与生产构建通过。
